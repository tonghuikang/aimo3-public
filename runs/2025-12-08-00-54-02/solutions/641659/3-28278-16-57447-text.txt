Circumcenter formula: Given three points (x1,y1),(x2,y2),(x3,y3). The circumcenter (Ux, Uy) can be found by solving linear equations derived from perpendicular bisectors. Use determinant method.

One method: solve for center (U) such that |U - P1|^2 = |U - P2|^2 and |U - P1|^2 = |U - P3|^2.

2*(x3 - x1)*Ux + 2*(y3 - y1)*Uy = x3^2 + y3^2 - x1^2 - y1^2.

    x1,y1 = P1
    x2,y2 = P2
    x3,y3 = P3
    # solve linear equations
    A = np.array([[2*(x2 - x1), 2*(y2 - y1)],
                  [2*(x3 - x1), 2*(y3 - y1)]], dtype=float)
    B = np.array([x2**2 + y2**2 - x1**2 - y1**2,
                  x3**2 + y3**2 - x1**2 - y1**2], dtype=float)
    # Solve for center
    try:

    except np.linalg.LinAlgError:
        return None, None
    Ux, Uy = sol[0], sol[1]
    R = math.hypot(Ux - x1, Uy - y1)
    return (Ux, Uy), R
