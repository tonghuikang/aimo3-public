    x1, y1 = p1

    x3, y3 = p3

    Uy = ((x1**2 + y1**2)*(x3 - x2) + (x2**2 + y2**2)*(x1 - x3) + (x3**2 + y3**2)*(x2 - x1))/D

def circle_center_and_radius(p1, p2, p3):
    O = circumcenter(p1,p2,p3)
    R = math.hypot(O[0] - p1[0], O[1] - p1[1])
    return O, R

def foot_of_perpendicular(point, line_pt1, line_pt2):
    # foot from point onto line through line_pt1, line_pt2
    # using projection formula
    x0, y0 = point
    x1, y1 = line_pt1
    x2, y2 = line_pt2
    # direction vector
    dx = x2 - x1
    dy = y2 - y1
    # param t
    t = ((x0 - x1)*dx + (y0 - y1)*dy) / (dx*dx + dy*dy)
    # foot point
    xf = x1 + t*dx
    yf = y1 + t*dy
    return (xf, yf)

def intersect_circles(O1, r1, O2, r2):
    # returns two intersection points (if any)
    x1, y1 = O1
    x2, y2 = O2
    d = math.hypot(x2 - x1, y2 - y1)
    if d == 0:
        raise ValueError("Same centers")
    # check for intersection existence
    if d > r1 + r2 or d < abs(r1 - r2):
        # no intersection
        return []
    # a = (r1^2 - r2^2 + d^2) / (2d)
    a = (r1*r1 - r2*r2 + d*d) / (2*d)
    # h^2 = r1^2 - a^2
    h_sq = r1*r1 - a*a
    if h_sq < -1e-12:
        return []
    h = math.sqrt(max(0.0, h_sq))

    # offset vectors
    offset_x = -ey * h
    offset_y = ex * h
    p_int1 = (px + offset_x, py + offset_y)
    p_int2 = (px - offset_x, py - offset_y)
    return [p_int1, p_int2]

    Q = foot_of_perpendicular(P, L1, L2)
    reflected = (2*Q[0] - P[0], 2*Q[1] - P[1])
    return reflected
