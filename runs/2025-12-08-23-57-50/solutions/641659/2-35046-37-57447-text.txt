Reflection of point P across line L: let line L be given by normalized direction vector v (unit) and normal vector n (unit). Compute projection onto line: P_proj = P - (dot(P - P0, n)) n (where P0 is any point on line). Then reflected point: P' = P_proj - (P - P_proj) = P_proj - (P - P_proj) = 2*P_proj - P.

Thus if n is unit normal to line, then reflect is P' = P - 2* (dot(P - P0, n)) n.

So we need n unit normal. For line EF, we can compute direction vector v = (xF - xE, yF - yE). Normal vector n = (v_y, -v_x) (or negative). Normalize.

Thus K' = K - 2*((K - any point on EF) dot n) * n.

We'll implement this.

Now we need N foot of perpendicular from D to line EF, which we computed earlier.

Now condition that B, N, K, K' are concyclic.

We can enforce using determinant condition.

Define points:

B (0,0), N (xN, yN), K (xK, yK), K' (xKp, yKp). Use sympy to compute determinant of 4x4 matrix:

|x_i   y_i   x_i^2 + y_i^2   1| for i=1..4. The determinant must be zero.

Thus we get equation in r (symbolic rational functions). Solve for r (positive real). Might be high-degree polynomial.

But maybe for small n the polynomial degree is manageable and we can find numeric root.

def solve_for_r(t, u):
    # t = BD, u = CD, with BC=1 (t+u=1)
    # unknown r >0
    # define function for cyclic condition determinant
    def f(r):
        # compute geometry
        # slopes
        mB = (2*t*r)/(t**2 - r**2)
        mC = - (2*u*r)/(u**2 - r**2)
        # intersection A
        xA = -mC/(mB - mC)
        yA = mB*xA
        # foot F on AB
        # line AB: mB*x - y = 0
        val1 = mB*t - r
        denom1 = mB**2 + 1
        xF = t - mB*val1/denom1
        yF = r + val1/denom1 # because -b1 = 1
        # foot E on AC: line: mC*x - y - mC =0
        val2 = mC*t - r - mC
        denom2 = mC**2 + 1
        xE = t - mC*val2/denom2
        yE = r + val2/denom2
        # line EF coefficients
        # compute line passing through (xE,yE) and (xF,yF)
        # A*x + B*y + C =0
        A = yF - yE
        B = xE - xF
        C = xF*yE - xE*yF
        # foot N from D(t,0) onto line EF
        valN = A*t + B*0 + C
        denomEF = A**2 + B**2
        xN = t - A*valN/denomEF
        yN = - B*valN/denomEF
        # circumcircle of ABC: B(0,0), C(1,0), A(xA,yA)
        # center O_ABC = intersection of perpendicular bisectors of BC (x=0.5) and of AB
        # Since B and C symmetric, O_ABC x-coordinate = 0.5
        # compute O_ABC y-coordinate using distance to B = distance to A
        xO = 0.5
        # radius squared R2 = (0.5)^2 + (0)^2 = 0.25
        # Actually O_ABC = (0.5, yO). Condition: distance O to B squared = (0.5)^2 + yO^2 = distance to A squared = (xA-0.5)^2 + (yA - yO)^2
        # Solve for yO:
        # 0.25 + yO^2 = (xA-0.5)^2 + (yA - yO)^2
        # Expand: 0.25 + yO^2 = (xA-0.5)^2 + yA^2 -2*yA*yO + yO^2
        # Cancel yO^2: 0.25 = (xA-0.5)^2 + yA^2 -2*yA*yO
        # Solve: yO = ((xA-0.5)**2 + yA**2 - 0.25) / (2*yA)
        # provided yA != 0 (nondegenerate)
        if abs(yA) < 1e-12:
            return 1e6
        yO = ((xA-0.5)**2 + yA**2 - 0.25) / (2*yA)
        # circumradius
        R2 = (0.5)**2 + yO**2
        # Now circumcircle of AFE: find its center O_AFE and radius
        # Compute circumcenter of three points (xA,yA), (xE,yE), (xF,yF)
        # Use formula for circumcenter:
        # Let D = 2*( (xA)*(yE - yF) + xE*(yF - yA) + xF*(yA - yE) )
        D = 2*(xA*(yE - yF) + xE*(yF - yA) + xF*(yA - yE))
        if abs(D) < 1e-12:
            return 1e6
        # Center coordinates:
        xO2 = ((xA**2 + yA**2)*(yE - yF) + (xE**2 + yE**2)*(yF - yA) + (xF**2 + yF**2)*(yA - yE)) / D
        yO2 = ((xA**2 + yA**2)*(xF - xE) + (xE**2 + yE**2)*(xA - xF) + (xF**2 + yF**2)*(xE - xA)) / D
        # radius squared of AFE
        R2_AFE = (xA - xO2)**2 + (yA - yO2)**2
        # Intersection of two circles: one centered at (xO,yO) radius sqrt(R2); the other centered at (xO2,yO2) radius sqrt(R2_AFE)
        # Solve for intersection points:
        # Let d = distance between centers
        dx = xO2 - xO
        dy = yO2 - yO
        d = mp.sqrt(dx*dx + dy*dy)
        # There are two intersections; one is A.
        # Compute a = (R2 - R2_AFE + d^2) / (2*d)
        a_len = (R2 - R2_AFE + d**2) / (2*d)
        # Height from line of centers to intersection points:
        h_sq = R2 - a_len**2
        if h_sq < -1e-12:
            return 1e6
        h = mp.sqrt(max(h_sq, 0))
        # Midpoint between centers along line:
        xm = xO + a_len * dx / d
        ym = yO + a_len * dy / d
        # intersection points:
        # (xm +- h * (-dy/d), ym +- h * (dx/d))
        # we need the point that is not A
        # compute both, check distance to A
        xK1 = xm + h * (-dy) / d
        yK1 = ym + h * (dx) / d
        xK2 = xm - h * (-dy) / d
        yK2 = ym - h * (dx) / d
        # Determine which is A (should be close to (xA,yA))
        # Compute distances
        d1 = (xK1 - xA)**2 + (yK1 - yA)**2
        d2 = (xK2 - xA)**2 + (yK2 - yA)**2
        # Choose other point as K
        if d1 < 1e-12:
            xK, yK = xK2, yK2
        else:
            xK, yK = xK1, yK1
        # Compute K' as reflection of K across line EF
        # line EF direction vector v = (xF - xE, yF - yE)
        vx = xF - xE
        vy = yF - yE
        # normal unit vector n = (vy, -vx) normalized
        norm = mp.sqrt(vx**2 + vy**2)
        nx = vy / norm
        ny = -vx / norm
        # point on line EF: use E
        # compute signed distance from K to line: d_line = (K - E) dot n
        d_line = (xK - xE)*nx + (yK - yE)*ny
        xKp = xK - 2*d_line*nx
        yKp = yK - 2*d_line*ny
        # compute determinant for cyclic condition for B,N,K,K'
        # matrix rows: [x, y, x^2+y^2, 1]
        # B(0,0)
        def det4(a,b,c,d):
            # compute 4x4 determinant using formula or sympy? we can compute using mp matrix.
            M = mp.matrix([[a[0], a[1], a[0]**2 + a[1]**2, 1],
                          [b[0], b[1], b[0]**2 + b[1]**2, 1],
                          [c[0], c[1], c[0]**2 + c[1]**2, 1],
                          [d[0], d[1], d[0]**2 + d[1]**2, 1]])
            return mp.det(M)
        Bpt = (0.0, 0.0)
        Npt = (xN, yN)
        Kpt = (xK, yK)
        Kppt = (xKp, yKp)
        det_val = det4(Bpt, Npt, Kpt, Kppt)
        # return determinant
        return det_val
    # Find root for r positive less than maybe min(t, u)
    # Use mpmath findroot starting near some guess.
    # Let's try initial guess r0 = 0.1
    try:
        root = mp.findroot(f, 0.1)  # may need multiple guesses
        return float(root)
    except Exception as e:
        # try alternative initial guesses
        for guess in [0.05,0.2,0.3]:
            try:
                root = mp.findroot(f, guess)
                return float(root)
            except Exception:
                pass
        # fallback: return None
        return None

def compute_ratio(t):
    u = 1 - t
    r = solve_for_r(t, u)
    if r is None:
        return None
    # Compute the ratio (CT*NB) / (BT*NE) for this configuration.
    # We need to compute T point as intersection of circle through B,K tangent to BN with BC.
    # Compute geometry again with known r, to find T and ratio.
    # We'll reuse same steps for geometry.
    t_val = t
    u_val = u
    # slopes, points...
    t0 = t_val
    # compute geometry again but now using numeric values
    # compute mB,mC etc
    mB = (2*t0*r)/(t0**2 - r**2)
    mC = - (2*u_val*r)/(u_val**2 - r**2)
    xA = -mC/(mB - mC)
    yA = mB*xA
    # F:
    val1 = mB*t0 - r
    denom1 = mB**2 + 1
    xF = t0 - mB*val1/denom1
    yF = r + val1/denom1
    # E:
    val2 = mC*t0 - r - mC
    denom2 = mC**2 + 1
    xE = t0 - mC*val2/denom2
    yE = r + val2/denom2
    # line EF coefficients
    A = yF - yE
    B = xE - xF
    Cc = xF*yE - xE*yF
    # foot N from D(t,0)
    valN = A*t0 + Cc  # B*0 =0
    denomEF = A**2 + B**2
    xN = t0 - A*valN/denomEF
    yN = - B*valN/denomEF
    # circumcenter O_ABC
    xO = 0.5
    yO = ((xA-0.5)**2 + yA**2 - 0.25) / (2*yA)
    # circumradius squared
    R2 = (0.5)**2 + yO**2
    # circumcenter O_AFE
    D = 2*(xA*(yE - yF) + xE*(yF - yA) + xF*(yA - yE))
    xO2 = ((xA**2 + yA**2)*(yE - yF) + (xE**2 + yE**2)*(yF - yA) + (xF**2 + yF**2)*(yA - yE)) / D
    yO2 = ((xA**2 + yA**2)*(xF - xE) + (xE**2 + yE**2)*(xA - xF) + (xF**2 + yF**2)*(xE - xA)) / D
    R2_AFE = (xA - xO2)**2 + (yA - yO2)**2
    # intersection points K (other than A) as before
    dx = xO2 - xO
    dy = yO2 - yO
    d = mp.sqrt(dx*dx + dy*dy)
    a_len = (R2 - R2_AFE + d**2) / (2*d)
    h_sq = R2 - a_len**2
    h = mp.sqrt(max(h_sq,0))
    xm = xO + a_len * dx / d
    ym = yO + a_len * dy / d
    xK1 = xm + h * (-dy) / d
    yK1 = ym + h * (dx) / d
    xK2 = xm - h * (-dy) / d
    yK2 = ym - h * (dx) / d
    # choose K not A
    if (xK1 - xA)**2 + (yK1 - yA)**2 < 1e-12:
        xK, yK = xK2, yK2
    else:
        xK, yK = xK1, yK1
    # Circle through B and K tangent to BN at B: find center O_T as intersection of line L (perp to BN at B) and perpendicular bisector of BK.
    # BN direction:
    vBN = (xN - 0, yN - 0)
    # line L: passes through B (0,0) direction n_perp = rotate vBN by 90 degrees
    # n_perp = (-vBN[1], vBN[0])
    n_perp = (-vBN[1], vBN[0])
    # perpendicular bisector of BK: midpoint M_BK = ((xK)/2, (yK)/2)
    # direction of bisector: perpendicular to BK => direction = rotate BK by 90 degrees: (-yK, xK)
    # So line eq: passes through M_BK with direction (-yK, xK)
    # Intersection of line L and that line gives center O_T.
    # Solve param equations: O_T = s * n_perp = M_BK + t * (-yK, xK)
    # Solve for s,t.
    # Write components:
    # s * n_perp[0] = M_BK[0] + t * (-yK)
    # s * n_perp[1] = M_BK[1] + t * (xK)
    # Solve linear equations.
    import numpy as np
    # Use sympy linear solve
    s, t = sp.symbols('s t')
    # but we are in numeric context; we can solve using simple formulas.
    # Represent as 2x2 linear system:
    # s * n_perp[0] - (-yK) * t = M_BK[0]
    # s * n_perp[1] - (xK) * t = M_BK[1]
    # Solve for s,t
    a11 = n_perp[0]; a12 = yK  # because -(-yK) = +yK? Let's derive: s*n_perp[0] = M_BK[0] + t*(-yK) => s*n_perp[0] + yK*t = M_BK[0]
    a21 = n_perp[1]; a22 = -xK  # similarly: s*n_perp[1] = M_BK[1] + t*(xK) => s*n_perp[1] - xK*t = M_BK[1]
    # So matrix [[a11, yK],[a21, -xK]] * [s, t]^T = [M_BK0, M_BK1]^T
    M_BK0 = xK/2
    M_BK1 = yK/2
    # Solve linear equations
    det = a11*(-xK) - a21*yK
    if abs(det) < 1e-12:
        # degenerate case (should not happen)
        return None
    s_val = (M_BK0*(-xK) - M_BK1*yK) / det
    # t not needed
    # Center O_T coordinates:
    O_Tx = s_val * n_perp[0]
    O_Ty = s_val * n_perp[1]
    # Radius = distance O_T to B = sqrt(O_Tx**2 + O_Ty**2)
    # Intersection with BC (y=0) again: solve circle equation (x- O_Tx)^2 + (0- O_Ty)^2 = radius^2 = O_Tx**2 + O_Ty**2
    # Expand: (x - O_Tx)^2 + O_Ty**2 = O_Tx**2 + O_Ty**2 => (x - O_Tx)^2 = O_Tx**2 => x - O_Tx = ± O_Tx
    # Solutions: x = O_Tx + O_Tx = 2*O_Tx or x = O_Tx - O_Tx = 0. So the two intersection points are x=0 (point B) and x=2*O_Tx.
    xT = 2*O_Tx
    # So T = (2*O_Tx, 0)
    # Compute distances:
    # CT = distance from C(1,0) to T: |1 - xT|
    CT = abs(1 - xT)
    BT = abs(xT)  # distance from B (0) to T
    NB = mp.sqrt((xN - 0)**2 + (yN - 0)**2)
    # NE = distance from N to E
    NE = mp.sqrt((xN - xE)**2 + (yN - yE)**2)
    ratio = (CT * NB) / (BT * NE)
    return float(ratio)
