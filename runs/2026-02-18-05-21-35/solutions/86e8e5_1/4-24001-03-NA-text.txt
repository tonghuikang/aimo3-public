Equivalent to compute the product of primes other than 3 after cancellation of common factors (including 3). So to minimize this product, we want a,b to share as many prime factors (especially large ones) as possible, and be multiples of each other (making lcm close to max). Ideally a|b (or b|a), then lcm = max. So we would like a|b. Since a+b=c, if a|b, then b = a * k, sum = a + a*k = a*(k+1) = c. So a must divide c. Also b = c - a = a*k => c - a = a*k => c = a*(k+1). So a is a divisor of c, and k = (c/a) - 1 must be integer >1 (since distinct). Then b = a*k = c - a. So any divisor a of c such that a < c-a (i.e., a < c/2) yields pair (a,c-a) where a divides c (since c = a*(k+1)). But does a divide b? b = c - a = a*k, so indeed a divides b. So lcm = b = c - a. That's the max. So lcm = c - a. That's likely close to c (since a is small). But we need to minimize non-3 part of lcm (which is lcm removing powers of 3). Since lcm = c - a, its non-3 part may be small if c - a is a power of 3 times small factor. But we can choose a to be power of 3 maybe.

Thus we can search for divisor a of c such that both a and c - a are positive distinct, and lcm_non3 = (c - a) after removing 3 factors (i.e., dividing by powers of 3). Since we want minimal such, we might choose a as large as possible to make c - a small. But a must be < c/2 (since a<b). So smallest possible max is just above c/2. That would give small lcm near c/2. The non-3 part would be (c - a) stripped of 3's.

The minimal lcm_non3 among all pairs is likely achieved by a divisor a close to c/2. Let's test with brute for given c values.
