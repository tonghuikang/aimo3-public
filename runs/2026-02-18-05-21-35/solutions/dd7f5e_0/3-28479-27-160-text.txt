def totient(n):
    result = n
    p=2
    while p*p<=n:
        if n%p==0:
            while n%p==0:
                n//=p
            result-=result//p
        p+=1
    if n>1:

    return result

There's no possibility of cancellation due to negative exponents because product is multiplication of Laurent polynomials, but binomial is a Laurent polynomial with only two monomials. So α must be factor of that polynomial. So classification complete.
