    # vector between centers
    O12 = O2 - O1
    d = np.linalg.norm(O12)
    # if circles coincide or no intersection, return None
    if d < 1e-12:
        return None
    # find point(s) of intersection
    # distance from O1 to line connecting intersection points
    # using formula for intersecting circles
    # a = (r1^2 - R2^2 + d^2) / (2d)
    a_len = (r1**2 - R2**2 + d**2) / (2*d)
    h_sq = r1**2 - a_len**2
    if h_sq < -1e-9:

    h = math.sqrt(max(h_sq, 0.0))

        return 2*proj - P

    # compute circle through B, K, N

    if O3 is None:
        cyclic = False
    else:

        cyclic = abs(np.linalg.norm(Kp - O3) - R3) < 1e-6

    # line1: direction perpendicular to BN => BN direction vector = N-B

    # line1 param: B + s * perp(dir1)

    M_BK = (B + K) / 2

    # solve for intersection O4 of lines: B + s*perp1 = M_BK + t*perp2

    A_mat = np.column_stack((perp1, -perp2))
    b_vec = M_BK - B

    try:
        sol = np.linalg.solve(A_mat, b_vec)
    except np.linalg.LinAlgError:
        return None
    s_param, t_param = sol
    O4 = B + s_param * perp1
    # radius of this circle = distance O4-B
    R4 = np.linalg.norm(O4 - B)
    # intersect this circle with BC (y=0). Equation: (x - O4_x)^2 + (0 - O4_y)^2 = R4^2
    # => (x - O4_x)^2 = R4^2 - O4_y^2

    x1 = O4[0] + x_offset
    x2 = O4[0] - x_offset

    if abs(x1) < 1e-6:
        T_x = x2
    elif abs(x2) < 1e-6:
        T_x = x1
    else:

        if abs(x1) < abs(x2):

        else:
            T_x = x1
    T = np.array([T_x, 0.0])
    # compute lengths

    BT = abs(T[0] - B[0])
    NB = np.linalg.norm(N - B)
    NE = np.linalg.norm(N - E_pt)

        return None

    }

That defines a unique circle passing through B, K, N and with BN tangent at N; but a circle through B,K,N will already be tangent to BN at N only if the radius is perpendicular to BN at N. That's an additional condition not automatically satisfied. So requiring tangency to BN at N is a strong condition. However phrase "circle tangent to line BN and passing through B and K" could be interpreted as circle that is tangent to line BN (anywhere) and also passes through B and K; not necessarily that the point of tangency is B or N. So there are two possibilities: the tangency point could be B, N, or elsewhere where the line BN touches the circle.

But if line BN touches the circle at any point, that point must be on BN and on the circle. Since circle already passes through B (which lies on BN), that point could be B (tangency at B) or some other point (like N). However the only other point on BN that could be on the circle is the second intersection of the circle with line BN (since a line can intersect a circle at two points). So tangency at the second intersection would mean line BN is tangent at that point, i.e., the line is tangent and passes through B as well as the tangent point; but then the line would intersect the circle only at that point, contradicting B being on the circle. So can't have distinct tangency point. Therefore the tangency point must be B. So original interpretation stands.

Thus our T is correct.
