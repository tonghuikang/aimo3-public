### 1.  All divisors of the binomials \(x^{m}+1\)

For a shifty function \(\alpha\) we must have  

\[
A(x)=\sum_{i=0}^{8}\alpha(i)x^{i}= \pm x^{c}\,P(x),
\qquad  
P(x)\mid x^{m}+1
\tag{1}
\]

for some integer \(m\neq0\) and some shift \(c\ge0\) with \(c+\deg P\le8\)
(the monomial \(x^{c}\) is a unit in \(\mathbb Z[x,x^{-1}]\)).
Hence every shifty \(\alpha\) is obtained by

* choosing an integer \(m\ge1\),
* taking *any* divisor \(P\) of \(x^{m}+1\) whose degree does not exceed 8,
* multiplying \(P\) by a monomial \(x^{c}\) ( \(0\le c\le 8-\deg P\) ),
* and finally choosing the overall sign \(\pm\).

We enumerated all such possibilities with a short Python program.

```python
import sympy as sp
x = sp.Symbol('x')

def cyclo(n):
    return sp.expand(sp.cyclotomic_poly(n, x))

# all even indices n with φ(n) ≤ 8
cand = [(2,1),(6,2),(10,4),(14,6),(18,6),(30,8),
        (4,2),(12,4),(20,8),(8,4),(24,8),(16,8)]

def divisors_of_binomial(m):
    """return all products of distinct cyclotomic factors of x^m+1
       whose total degree ≤ 8"""
    # cyclotomic factors of x^m+1 are those n|2m but n∤m
    factors = [(n, sp.totient(n)) for n in sp.divisors(2*m)
               if n not in sp.divisors(m)]
    polys = [1]                                 # empty product = 1
    for mask in range(1, 1<<len(factors)):
        prod = 1
        deg  = 0
        for i,(n,d) in enumerate(factors):
            if mask>>i & 1:
                prod = sp.expand(prod*cyclo(n))
                deg  += d
        if deg <= 8:
            polys.append(prod)
    return polys

shifty = set()
for m in range(1,101):                # m up to 100 is more than enough
    for P in divisors_of_binomial(m):
        degP = sp.degree(P, x)
        for c in range(0, 9-degP):
            shifty.add(sp.expand( P * x**c ))
            shifty.add(sp.expand(-P * x**c))

print(len(shifty))
```

```
160
```

functions \(\alpha\)) arise from (1).  Increasing the bound on \(m\) (e.g. to
200) does **not** produce any new functions, confirming that the list is
