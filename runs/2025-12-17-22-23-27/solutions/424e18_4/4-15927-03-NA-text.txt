However we only need the exponent of 5, which we can compute via Legendre's formula using binomial valuations.

Recall Catalan number C_n = binom(2n, n)/(n+1). So v_p(C_n) = v_p( binom(2n,n) ) - v_p(n+1).

We can compute v_5 using Legendre's formula for factorial valuations: v_p( binom(2n,n) ) = v_p((2n)! ) - 2* v_p( n! ).

Thus v_5(C_n) = (v_5((2n)!) - 2*v_5(n!)) - v_5(n+1).

We can compute v_5 for n up to 2^19 efficiently using Legendre's formula, which sums floor(n/5^k). That's easy.
