At each depth d (starting from 0), there are 2^d nodes each of size 2^{m-d}. Each node size is 2^{m-d}, which is 2k with k = 2^{m-d-1}.

Therefore N = product_{d=0}^{m-1} (C_{2^{m-d-1}})^{2^d}.
