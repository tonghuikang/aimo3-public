def min_ratio_for_sum(s):
    best = None
    best_triple = None
    # iterate triples a<b<c distinct, sum = s
    # naive O(s^2) loops
    for a in range(1, s-2):
        for b in range(a+1, s-1):
            c = s - a - b
            if c <= b:
                continue
            # distinct automatically
            l = math.lcm(a,b,c)
            ratio = l/s
            if best is None or ratio < best:
                best = ratio
                best_triple = (a,b,c,l)
    return best, best_triple

    best = None
    best_triple = None
    for a in range(1, s-2):
        for b in range(a+1, s-1):
            c = s - a - b

### 1.  What the problem asks for  

For a positive integer \(n\ge 6\) we call an integer **\(n\)-Norwegian** if it possesses three **distinct** positive divisors whose sum is exactly \(n\).  
\(f(n)\) is defined as the *smallest* such integer.

\[
a+b+c=n,
\qquad N=\operatorname{lcm}(a,b,c)
\]

Conversely, for any \(n\)-Norwegian integer \(N\) we can take three of its divisors and obtain such a triple.

\[
\boxed{f(n)=\min_{a<b<c,\;a+b+c=n}\operatorname{lcm}(a,b,c)} .

\[
a=dx,\;b=dy,\;c=dz,\qquad n=d\,(x+y+z)=d\,s .
\]

\[
f(n)=\frac{n}{s}\,\operatorname{lcm}(x,y,z)
