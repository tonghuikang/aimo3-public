def proper_divisors(x):
    divs=set()
    for i in range(1,int(math.isqrt(x))+1):
        if x%i==0:
            divs.add(i)
            divs.add(x//i)
    divs.discard(x)
    return divs

def f_bruteforce_L_general(n, max_L_factor=3):
    # search L from lower bound (ceil(6n/11)) up to maybe max_L_factor * n
    lower = (6*n + 10)//11  # ceil(6n/11)

        d = n - L
        if d > 0:
            # need two distinct proper divisors a,b of L sum to d
            divs = proper_divisors(L)
            for a in divs:
                b = d - a
                if b != a and b in divs:
                    return L
        # case2: three proper divisors sum to n, all < L

        divs = list(proper_divisors(L))

                    b = divs[j]
                    c = n - a - b
                    if c != a and c != b and c in divs and c > b:
                        # distinct, c present
                        return L
    return None

We have L = n * pq / D. Let g = gcd(pq, D). Write pq = g * p', D = g * d' with gcd(p', d') = 1. Then L = n * (g * p') / (g * d') = n * p' / d'. So L integer iff d' divides n. Since p', d' are coprime.

Now a = L/p = n * p' / (d' * p) = n * p' / (d' * p). Since p' = (pq)/g, p' contains factor p/gcd(p,D) maybe? Let's compute directly: a = L/p = (n * pq / D)/p = n * q / D. So integer a iff D divides n * q. Since D = g * d', and gcd(q, d') may be >1.

Similarly, b integer iff D | n * p.

Thus we need D | n * q and D | n * p. Equivalent to D/gcd(D,p) | n and D/gcd(D,q) | n. So the condition is n divisible by lcm(D/gcd(D,p), D/gcd(D,q)). That is our D_needed.
