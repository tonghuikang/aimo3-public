Let A = K * (p-1)/p = K - K/p. Write K/p = q + r/p, where q = K//p, r=K mod p. So A = K - q - r/p = (K - q) - r/p.

Since 0 < r/p < 1, A is non-integer; floor(A) = K - q - 1.

Now the extra term B = K * (p-1)/p * (c - 1)/M = A * (c - 1)/M. Since (c - 1)/M is small (<1 except c large). For c=4M case, (c - 1)/M = (4M - 1)/M = 4 - 1/M ≈ 4; thus B = A * approx 4, which could be large.

Thus X = A * (1 + (c-1)/M) = A + A*(c-1)/M.

Thus floor(X) = floor(A + B).

We need to compute floor(A + B). Since A = integer - r/p (i.e., not integer), B = A*(c - 1)/M.

Now we can compute floor(A + B) exactly using integer arithmetic with the actual values for each case, as we did for c=4M using derived expression.
