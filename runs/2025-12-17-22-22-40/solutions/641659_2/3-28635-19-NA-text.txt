Compute a+b = BD/(BD^2 - r^2) + CD/(CD^2 - r^2) = (BD(CD^2 - r^2) + CD(BD^2 - r^2))/((BD^2 - r^2)(CD^2 - r^2)) = [BD*CD^2 - BD r^2 + CD*BD^2 - CD r^2] / ((BD^2 - r^2)(CD^2 - r^2)) = [BD*CD^2 + CD*BD^2 - (BD+CD) r^2] / ((BD^2 - r^2)(CD^2 - r^2)).

Also L = BD+CD.

Thus x_A = L * b/(a+b) = (BD+CD) * (CD/(CD^2 - r^2)) / (a+b). So numerator: L*CD/(CD^2 - r^2). Denominator a+b given above. So x_A = (L*CD/(CD^2 - r^2)) * ((BD^2 - r^2)(CD^2 - r^2))/ [BD*CD^2 + CD*BD^2 - (BD+CD) r^2] = L*CD*(BD^2 - r^2)/[BD*CD^2 + CD*BD^2 - (BD+CD)r^2] = (L * CD * (BD^2 - r^2))/[BD*CD^2 + CD*BD^2 - L r^2].

Simplify denominator: BD*CD^2 + CD*BD^2 = BD*CD (CD + BD) = BD*CD*L.

Thus denominator = BD*CD*L - L r^2 = L*(BD*CD - r^2). So x_A = (L * CD * (BD^2 - r^2)) / (L*(BD*CD - r^2)) = CD * (BD^2 - r^2) / (BD*CD - r^2).

Thus x_A = CD (BD^2 - r^2)/(BD*CD - r^2).

Similarly, y_A = m * x_A = (2r BD/(BD^2 - r^2)) * x_A. Compute:

y_A = (2r BD/(BD^2 - r^2)) * (CD (BD^2 - r^2)/(BD*CD - r^2)) = 2r BD * CD / (BD*CD - r^2) = 2 r BD CD / (BD*CD - r^2).

Thus A coordinates:

- A.x = CD (BD^2 - r^2) / (BD*CD - r^2).
- A.y = 2 r BD CD / (BD*CD - r^2).

Nice!

Thus we have symmetrical formula: swapping BD and CD yields symmetric expressions for x-coordinate: if we swapped B and C, we would get x_A' = BD (CD^2 - r^2)/(BD*CD - r^2). Indeed.
