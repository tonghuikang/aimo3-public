    # Compute distance d between centers

def compute_triangle(d, a, r):
    # B=(0,0), C=(a,0)
    B = (0.0, 0.0)
    C = (a, 0.0)
    # incircle center I
    I = (d, r)

    # AB slope m_B
    if abs(d**2 - r**2) < 1e-12:
        # degenerate
        return None
    mB = (2*d*r) / (d**2 - r**2)
    # AC slope m_C
    if abs((a-d)**2 - r**2) < 1e-12:
        return None

    # Find A intersection of y = mB x and y = mC (x - a)
    # Solve mB * x = mC * (x - a)

    xA = -mC * a / denominator

def residual(r, d, a):
    data = compute_triangle(d, a, r)
    if data is None:
        return None
    B = data['B']; K = data['K']; Kp = data['Kp']; N = data['N']
    # circumcenter of B, K, Kp
    O = circumcenter(B, K, Kp)
    if O is None:
        return None
    R = distance(O, B)
    # residual: distance from O to N minus R
    return distance(O, N) - R

So these lines intersect near D: solving approx: (2r/d) x = (2r/(a-d))(a - x) => divide 2r: x/d = (a-x)/(a-d) => cross multiply: x (a-d) = d (a - x) => x (a-d) = a d - d x => x (a-d + d) = a d => x a = a d => x = d. So intersection point A tends to D (x=d,y≈??). Indeed y = (2r/d) * d = 2r. So A approaches (d,0) as r →0, with small y coordinate ~2r. So triangle becomes degenerate, A near D, B and C far.

Thus line EF: Points F and E are near D as well. Let's compute E and F coordinates for small r using approximations.

We derived formulas for F coordinate using x_F = d / sqrt(1+m_B^2) and y_F = m_B x_F. For small m_B, sqrt(1+m_B^2) ≈ 1 + m_B^2/2. So x_F ≈ d (1 - m_B^2/2). y_F ≈ m_B d (1 - m_B^2/2). With m_B ≈ 2r/d, we get x_F ≈ d (1 - (2r/d)^2/2) = d (1 - 2r^2/d^2) ≈ d - 2r^2/d. So x_F ≈ d - (2r^2)/d. y_F = m_B x_F ≈ (2r/d) * d = 2r (ignoring small correction). So F ≈ (d - 2r^2/d, 2r). Similarly E: x-coordinate x_E = a - (a-d)/sqrt(1+m_C^2). With m_C ≈ -2r/(a-d), m_C^2 = (4r^2)/(a-d)^2. sqrt(1+m_C^2) ≈ 1 + m_C^2/2. So (a-d)/sqrt ≈ (a-d)*(1 - m_C^2/2) = (a-d) - (2r^2)/(a-d). Thus x_E ≈ a - [(a-d) - (2r^2)/(a-d)] = a - (a-d) + (2r^2)/(a-d) = d + (2r^2)/(a-d). So x_E ≈ d + 2r^2/(a-d). y_E = -m_C * (a-d)/sqrt(1+m_C^2). Since m_C negative, -m_C positive. m_C = -2r/(a-d). So -m_C = 2r/(a-d). Then y_E ≈ (2r/(a-d)) * ((a-d) - (2r^2)/(a-d)) = 2r * (1 - (2r^2)/(a-d)^2) ≈ 2r - (4r^3)/(a-d)^2.

Thus both E and F are approximately (d ± something small, 2r). So EF is a segment roughly horizontal (y coordinate ~2r) with x from d - 2r^2/d to d + 2r^2/(a-d). So EF is a small segment centered near x = d, with length approx L = x_E - x_F ≈ 2r^2/d + 2r^2/(a-d) ≈ 2r^2 (1/d + 1/(a-d)). That is small O(r^2). So EF is almost horizontal line at y≈2r.

Now D = (d,0). Foot N from D onto EF: Since EF nearly horizontal at y≈2r, foot of perpendicular from D (0,0?) Actually D at (d,0) onto line y ≈ 2r? The perpendicular is vertical line x = d, foot is point (d, y≈2r). So N ≈ (d, 2r). Indeed N lies on EF near its midpoint.

Thus NB = distance from B (0,0) to N (d, 2r) = sqrt(d^2 + (2r)^2) ≈ sqrt(d^2 + 4r^2) ≈ d * sqrt(1 + 4r^2/d^2) ≈ d + 2r^2/d (approx). NE = distance from N to E (approx E ≈ (d + 2r^2/(a-d), 2r)). So NE ≈ difference in x: E_x - d = 2r^2/(a-d). Since y coordinates same (≈2r), vertical difference negligible. So NE ≈ 2r^2/(a-d). Similarly, NB ≈ sqrt(d^2 + 4r^2) ≈ d + 2r^2/d.

Thus NB/NE ≈ (d + 2r^2/d) / (2r^2/(a-d)) = (d (a-d) / (2r^2)) * (1 + (2r^2)/(d^2)). For small r, leading term: NB/NE ≈ d (a-d) / (2r^2). So NB/NE ~ (d*CD) / (2r^2) where CD = a-d.

Thus NB/NE tends to infinity as r → 0. So ratio NB/NE diverges.
