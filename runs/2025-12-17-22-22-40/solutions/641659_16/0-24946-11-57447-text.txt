Then find t ≠0 such that X also satisfies distance to O1 equals r1. Since we already have A satisfying that, the other solution corresponds to t = -2 * (v·(A - O1)) / (v·v)? Let's solve.

Let line L: X = A + λ * v (any λ). Since A is on L, we can param from A.

We want X satisfy (X - O1)·(X - O1) = r1^2.

Plug in: (A + λv - O1)² = r1².

Expand: (A - O1)² + 2λ v·(A - O1) + λ² v² = r1².

But (A - O1)² = r1² because A lies on circle. So cancel: 2λ v·(A - O1) + λ² v² = 0.

Factor λ: λ (2 v·(A - O1) + λ v²) = 0. Solutions λ=0 (gives A) or λ = -2 * v·(A - O1) / v². So K = A + λ v where λ = -2*(v·(A - O1))/|v|².

Thus compute O1 = center of circ_ABC. Compute O2 = center of circ_AFE. Compute v = rotate90(O2 - O1) = (-(y2-y1), x2-x1). Compute lambda accordingly. Compute K.

That gives K.

Now we can compute reflection K' across line EF using vector formula: reflect point across line defined by two points.

Compute K' = reflect K across line EF.

Now compute circle passing through B,N,K: find its circumcenter and radius.

But we need to compute residual: difference between distance of K' to circumcenter and radius.

We'll solve f(s) = distance(K', O_BNK) - R_BNK = 0.

Now we can find s root.

def rotate90(v):
    # v is tuple (x,y)
    return (-v[1], v[0])

def circumcenter(p1, p2, p3):
    # return center (x,y) and radius
    # using formula for circumcenter of triangle
    # Compute perpendicular bisectors intersection
    (x1,y1),(x2,y2),(x3,y3)=p1,p2,p3
    # Compute determinant d = 2*(x1*(y2-y3)+x2*(y3-y1)+x3*(y1-y2))
    d = 2*(x1*(y2-y3) + x2*(y3-y1) + x3*(y1-y2))
    if abs(d) < 1e-12:
        # collinear
        return None, None
    ux = ((x1**2+y1**2)*(y2-y3) + (x2**2+y2**2)*(y3-y1) + (x3**2+y3**2)*(y1-y2)) / d
    uy = ((x1**2+y1**2)*(x3-x2) + (x2**2+y2**2)*(x1-x3) + (x3**2+y3**2)*(x2-x1)) / d
    r = math.hypot(ux-x1, uy-y1)
    return (ux,uy), r

def reflect_point_across_line(P, Q, R):
    # reflect point P across line through Q,R
    # formula: project onto line, then reflect.
    # Let line direction v = R-Q
    vx, vy = R[0]-Q[0], R[1]-Q[1]
    # Normalize? Not needed.
    # Compute projection of vector PQ onto v:
    # Parameter t = ((P-Q)·v) / (v·v)
    t = ((P[0]-Q[0])*vx + (P[1]-Q[1])*vy) / (vx*vx + vy*vy)
    # foot point H = Q + t*v
    Hx = Q[0] + t*vx
    Hy = Q[1] + t*vy
    # reflection: P' = 2H - P
    return (2*Hx - P[0], 2*Hy - P[1])
