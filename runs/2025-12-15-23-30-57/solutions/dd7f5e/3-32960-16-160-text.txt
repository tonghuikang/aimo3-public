- There exists β ∈ ℱ and distinct integers k≠l such that for all n ∈ ℤ,
  S_n(α) ★ β = 1 if n ∈ {k,l}, else 0.

Goal: count number of shifty functions α ∈ ℱ.

Interpretation: For all n, inner product of shifted α with β yields exactly two n values where it's 1, else 0.

Let α: ℤ→ℤ with support inside [0,8]. Define S_n(α)(t) = α(t+n). Then S_n(α) ★ β = Σ_{t∈ℤ} α(t+n)·β(t). Changing variable m = t + n => t = m - n, sum over m: Σ_{m} α(m)·β(m-n). This is convolution of α with reversed β: (α * β_rev)(n) where β_rev(s) = β(-s). Indeed, define B(s) = β(-s). Then sum α(m)·B(n - m) = (α ∗ B)(n). So S_n(α)★β = (α ∗ B)(n). Condition: (α ∗ B)(n) = δ_{n,k} + δ_{n,l}.

Thus α ∗ B = x^k + x^l as Laurent polynomials, where α corresponds to polynomial A(x) = Σ_i α(i) x^i, B is polynomial B(x) = Σ_j B(j) x^j.
